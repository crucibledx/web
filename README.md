# Crucible Web

> Marketing site and documentation for [Crucible](https://crucibledx.dev) — the Developer Experience infrastructure platform.

|--------------------------------------------|--------------------|----------------|

## Stack

- [Astro](https://astro.build) — static-first web framework
- [Starlight](https://starlight.astro.build) — documentation plugin for Astro
- [Tailwind CSS](https://tailwindcss.com) — utility-first styling
- [Cloudflare Pages](https://pages.cloudflare.com) — hosting

## Development

```bash
bun install
bun run dev          # start dev server
bun run build        # production build
bun run preview      # preview production build locally
```
